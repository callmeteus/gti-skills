# Learnings

One block per lesson learned during infrastructure work. Each block is written by `knowledge.py learn` with a date, an area, what happened, the rule that prevents a repeat, and a source. Merge a near-copy into an existing block instead of appending a second one. Keep this file short. Never write a secret value here, only a variable name or a secret-store path.
