# Project infrastructure knowledge

This folder holds ACME's committed project knowledge: access paths, tool and CLI notes, host aliases and records. It lives at the repository root in `.gti/infra-expert/`. Secret values are not stored here; paths and key names are.

| File | Contents |
|------|----------|
| `access.md` | Access paths, secret locations and the MiniStack endpoint |
| `mcp.md` | The six `acme-prod` MCP tools and their inputs |
| `cli.md` | The environment's CLI commands |
| `hosts.md` | Host aliases and the target for each one |
| `learnings.md` | Recorded lessons |
| `mcp-gaps.md` | Capabilities the MCP does not have yet |
| `records.md` | Inventory and record locations |
| `conventions.md` | Terraform layout, naming and tags |
