# Originality

References set the level. They never set the layout.

When the user shows references, or when you think of a familiar post, extract what makes it good (depth, texture, type contrast, photo treatment, furniture) and build something new with those qualities. A piece that a viewer could match to one specific reference is a failure, even if it looks good.

## Rules

- **Never clone:** do not reproduce a reference's composition, copy, palette, and subject together. Change at least the structure, the palette, and the type pairing.
- **Combine:** build each variant from at least two of the structures in [composition.md](composition.md), or one structure with an unusual hero treatment.
- **Derive the palette from the brand:** start from the user's colors or the subject's colors, then apply the palette strategy (one field, one hot accent, one neutral).
- **Write new copy:** never reuse a reference's text, brand, or slogan. Write for the user's offer in the user's language.
- **Vary the set:** when you deliver two to four variants, no two share the same structure and hero treatment.
- **Templates only on request:** `generate --template` is for repeatable formats the user asked for (a weekly carousel, a price card series). For a new piece, write original HTML.
- **Respect rights:** no third-party logos, brand names, or recognizable people from references. Use the user's assets or openly licensed photos.

## Self-check before handing over

- [ ] Could someone point to the reference this was copied from? If yes, change the structure.
- [ ] Is there a hero, and does the type interlock with it?
- [ ] Are there at least three planes of depth and a texture layer?
- [ ] Is the headline 6 to 12 times the supporting text, in two distinct voices?
- [ ] Does the palette have one field, one accent used in a few places, and a neutral?
- [ ] Are there two to five kinds of native furniture, each carrying a purpose?
- [ ] Does the piece use the whole canvas, with intentional bleed and cropping?
- [ ] Would it sit next to a strong professional feed without looking cheaper?
