## Overview

Interfaces generated by AI tools share a recognizable look: purple gradients, glow, emoji icons, gradient text, pill badges, "Welcome back!" headers, and gaps that follow no scale. The screen works, but it reads as a template.

Unslop Interface gives an agent a fixed order of six passes, a checklist of the tells, and a concrete before and after for each pass. The agent inventories the tells, fixes them one pass at a time in the UI code (or describes exact changes for a screenshot), and reports what changed. The passes and measurements were distilled from the Damir Sokolovsky clip "Unslopping a vibecoded dashboard" with the Video to Skill skill, and the tabular figures rule for changing numbers from a clip by Nexvyn.

```text
  UI code or screenshot
          │
          v
  inventory the tells ──> references/quality/slop-tells.md
          │
          v
  spacing ─> radius ─> color ─> icons ─> type and copy ─> data display
          │            references/passes/0N-*.md
          v
  verify against the inventory
          │
          v
  unslop report (per pass before and after, files, tokens)
```

| This skill does | This skill does not |
|-----------------|---------------------|
| Remove decorative gradients, glow, emoji icons, and filler copy | Change what the screen asks the user to do |
| Normalize spacing, radius, icon alignment, and type | Audit accessibility or performance |
| Edit HTML, CSS, Tailwind, React, Vue, or Svelte code in place | Build a new screen from nothing |
| Reuse the project's tokens, icon set, and chart library | Add new visual trends in place of the old ones |

## Features

- **Ordered passes:** spacing, corner radius, color, icons and alignment, typography and copy, and data display, each in its own reference file.
- **Measured examples:** the spacing and icon passes include the exact values from the source frames, before and after, and the typography pass includes a measured timer that stops shifting with tabular figures.
- **Tells checklist:** one table of tells, each mapped to the pass that fixes it, used before and after the work.
- **Keeps the information:** every number, item, and action stays; only decoration and filler go.
- **Precise vocabulary:** the report names each fix with its UI term (affordance, leading, tabular numbers, sticky positioning).
- **Report template:** before and after per pass, changed files, new tokens, and tells kept on purpose.
- **Measured before and after (added):** when the app runs, the bundled lintapple linter measures gaps, insets, radii, contrast, fonts, type sizes, tabular numbers, and banned copy in Chromium; findings join the inventory under the pass that fixes them, and the report shows counts before and after. Shared with Frontend Design Review through `packages/lintapple`.
- **Works without tools:** from source code, a screenshot, or both; lintapple is used only when the app can run.

## Requirements

| Dependency | Version | Purpose | Auto-installed |
|------------|---------|---------|:--------------:|
| Node.js | 22+ | Runs lintapple, the measured UI checks (optional) | No |
| lintapple | 0.1.24, from `packages/lintapple` | Measured checks of the rendered page; built on install and update, or run with `npx` | Yes |
| Chromium for Playwright | Matches lintapple's Playwright | Browser lintapple drives; the runner prints the install command when it is missing | No |

The agent needs to read images to work from screenshots. Without image input, share the component code.

## Installation

From the repository root, install the skill into any supported agent:

```bash
node packages/cli install --harness claude --skill unslop-interface
```

The same command works in PowerShell. Use a comma separated list or `all` for several agents, `--scope user` to install for every project, and `--dry-run` to preview.

| Agent | Id | Project folder | User folder |
|-------|----|----------------|-------------|
| Cursor / Cursor CLI | `cursor` | `.cursor/skills` | `~/.cursor/skills` |
| Claude / Claude Code | `claude` | `.claude/skills` | `~/.claude/skills` |
| Antigravity | `antigravity` | `.agents/skills` | `~/.gemini/antigravity/skills` |
| OpenCode | `opencode` | `.opencode/skills` | `~/.config/opencode/skills` |
| Cline | `cline` | `.cline/skills` | `~/.cline/skills` |
| Kilo Code | `kilo` | `.kilocode/skills` | `~/.kilocode/skills` |
| Kiro | `kiro` | `.kiro/skills` | `~/.kiro/skills` |
| Codex | `codex` | `.agents/skills` | `~/.agents/skills` |
| GitHub Copilot | `copilot` | `.github/skills` | `~/.copilot/skills` |
| Muse Code | `muse` | `.agents/skills` | `~/.agents/skills` |

The skill is one self-contained folder, identical for every agent. To copy it by hand, put `skills/unslop-interface` in your agent's folder (macOS and Linux, Claude Code shown):

```bash
mkdir -p .claude/skills && cp -r skills/unslop-interface .claude/skills/
```

Windows (PowerShell):

```powershell
New-Item -ItemType Directory -Force .claude\skills | Out-Null
Copy-Item -Recurse skills\unslop-interface .claude\skills\
```

Each agent has a short guide in `skills/unslop-interface/harnesses/<id>/GUIDE.md` covering install paths, how to invoke the skill, and how to confirm it loaded.

## Quick Start

```text
Unslop src/pages/Dashboard.tsx. It looks too AI generated.
```

The agent lists the tells it finds, runs the six passes in order on the component, and returns a report with before and after per pass and the files it changed.

## Usage

### Input

| Input | Required | Example |
|-------|:--------:|---------|
| Interface | Yes | A component file such as `Dashboard.tsx`, a page's HTML and CSS, or a screenshot |
| Design tokens | No | The project's spacing scale, radius, colors, font, and icon library |
| Scope | No | Only some passes ("just spacing and color"), or report without editing code |
| Theme | No | Keep light or dark; the skill keeps the current theme by default |

### Examples

```text
This dashboard looks vibecoded. Clean it up: src/app/dashboard/page.tsx
```

```text
De-slop this settings screen. Screenshot only, give me the exact changes.
```

```text
Run only the color and typography passes on components/StatsCard.vue.
```

## How It Works

```text
  1. Inventory      list every tell, note existing tokens
          │
  2. Spacing        one scale, shared content edges
          │
  3. Radius         at most three radii, no pill inputs
          │
  4. Color          neutral base, color only for meaning
          │
  5. Icons          one icon set, one column, dots for categories
          │
  6. Type and copy  calm weights, sentence case, numbers with context, tabular figures
          │
  7. Data display   labeled axes, colors that match a key
          │
  8. Verify         re-check the inventory, write the report
```

## Reference

### Pass files

Each file holds the goal, the before and after from the source, steps, and a check. The agent reads a file only when it reaches that pass.

| File | Pass | Typical fixes |
|------|------|---------------|
| `references/passes/01-spacing.md` | Spacing | Arbitrary gaps snapped to a scale, aligned content edges |
| `references/passes/02-radius.md` | Corner radius | Pills replaced, radius tokens |
| `references/passes/03-color.md` | Color and effects | Gradients, glow, and tinted glass removed |
| `references/passes/04-icons.md` | Icons and alignment | Emoji replaced by a line icon set, fixed inset and gap, actions given affordance |
| `references/passes/05-typography-and-copy.md` | Typography and copy | Caps, exclamation marks, filler headers, and redundant page taglines removed; tabular figures for changing numbers; body leading and ligatures |
| `references/passes/06-data-display.md` | Data display | Axes, units, colors tied to a legend, sticky table headers |
| `references/quality/slop-tells.md` | Checklist | Every tell mapped to its pass |
| `references/quality/vocabulary.md` | Vocabulary | Precise UI terms to name each fix in the report |
| `references/lintapple/lintapple.md` | Measured checks | Running lintapple, adapting its policy, reading findings (shared with Frontend Design Review) |

### scripts/lintapple/run.mjs

Shared with the other UI skill and synced from `packages/lintapple/agent`.

```bash
node skills/unslop-interface/scripts/lintapple/run.mjs http://localhost:3000 --project <app folder> --config <policy file>
```

| Argument | Default | Description |
|----------|---------|-------------|
| `<url>` | Required | The running page: a dev server, preview URL, or `file://` page |
| `--project` | Current folder | The app folder; its `ui-policy.json` and `node_modules/lintapple` are used when present |
| `--config` | Project policy, else the default | Policy file adapted to the design system |
| `--ready` | None | Selector that is visible when the page is ready |
| `--interactions` | None | lintapple interaction plan for menus, dialogs, and other states |
| `--out` | OS temp folder | Where to save the full JSON report |
| `--top` | `15` | Problem groups printed in the summary |
| `--write-policy FILE` | - | Writes the default policy to adapt |
| `--where` | - | Shows which lintapple runs: the project's, the gti-skills package, or `npx` |

## Output

````markdown
# Unslop report: Overview dashboard

## Inventory

- **Source:** src/pages/Dashboard.tsx
- **Existing tokens reused:** Tailwind spacing scale, Lucide icons
- **Tells found:** purple gradient background, gradient heading, emoji nav icons,
  pill badges, "Welcome back!" title, "+12%!!"

## Passes

### 5. Typography and copy

- **Before:** "Welcome back, Damir!" bold gradient title; "+12%!!" with a fire emoji.
- **After:** "October 2026" regular weight; "+12% vs last month".
- **Files:** src/pages/Dashboard.tsx
````

| Section | Contents |
|---------|----------|
| Inventory | Source, reused tokens, and the tells found |
| Passes | One block per pass that changed something: before, after, files |
| Tokens introduced | New tokens with their values and use |
| Kept on purpose | Tells left in place and why |
| Not covered | Issues outside the scope, such as flows or accessibility |

The template is `assets/templates/unslop-report.md`.

## Troubleshooting

<details>
<summary><strong>lintapple says Chromium is missing</strong></summary>

Playwright's browser is not installed. Run the command the runner prints, for example:

```bash
cd packages/lintapple && npx playwright install chromium
```

</details>

<details>
<summary><strong>lintapple reports every font and size as wrong</strong></summary>

The default policy expects Apple system fonts and a fixed type scale. Write it out, set `fonts`, `fontSizes`, and `typeRules` to the project's design system, and pass it with `--config`:

```bash
node skills/unslop-interface/scripts/lintapple/run.mjs --write-policy /tmp/ui-policy.json
```

</details>

<details>
<summary><strong>The agent does not see the skill</strong></summary>

Restart the agent session after installing, and confirm the folder is in the path your agent reads (see the table in [Installation](#installation)).

</details>

<details>
<summary><strong>The result switched my light theme to dark</strong></summary>

The source example ends on a dark theme, but the skill keeps the current theme by default. Say "keep the light theme" in the request, and the color pass builds the neutral ramp on light surfaces.

</details>

<details>
<summary><strong>The agent removed my brand color</strong></summary>

The color pass keeps one brand accent. Name the brand color or point to the token in the request, and the agent keeps it and lists it under "Kept on purpose".

</details>

<details>
<summary><strong>The agent wants to add an icon library</strong></summary>

The icons pass uses the project's icon library first and asks before adding a dependency. Name the library you want, or ask for inline SVG.

</details>

## Limitations

- The Damir Sokolovsky clip is silent. The pass order and measurements come from the frames; the reasons and general rules are written for this skill.
- Reviews from a screenshot cannot see hover, focus, loading, or responsive states.
- lintapple measures only a running page, and measures layout gaps, alignment, and radii only on elements marked with `data-ui-*` attributes or policy selectors.
- The skill polishes look and copy, not flows, conversion, or accessibility.
- Chart changes depend on the data the screen actually has; the agent cannot invent a new series.
