# Format: full transcript

For when the user wants every word, organized and readable, with the visuals in place.

Template: [assets/templates/full-transcript.md](../../assets/templates/full-transcript.md)

## Structure

1. **Frontmatter:** title, source, channel, duration, caption source (manual, auto-generated, or Whisper).
2. **Sections:** one per chapter or topic, each with a timestamp link.
3. **Paragraphs:** the spoken text grouped by thought, with a timestamp link every two to three minutes.
4. **Frames:** placed where the speaker refers to them.

## Rules

- Keep the speaker's wording. Fix only obvious caption errors (names, jargon, punctuation) and remove filler such as "um" and repeated words.
- Never summarize in this format. If the user wants a summary too, add a short Overview at the top.
- Label speakers when the video has more than one and the voices are clear. Otherwise do not guess.
- Mark unclear audio as `[inaudible]` instead of inventing text.
- Note the caption source, because auto-generated captions can contain errors.
