# Final checklist

Run through this before delivering.

## Content

- [ ] Every section heading links to its moment in the video.
- [ ] No blockquote from the draft is left; all raw transcript is condensed (unless the format is full transcript).
- [ ] Commands and code match what the frames show.
- [ ] Names, product names, and numbers are spelled correctly (auto-generated captions often get them wrong).
- [ ] Nothing is presented as shown that was only inferred.
- [ ] The frontmatter has title, source link, and channel.

## Visuals

- [ ] Every embedded frame adds information; decorative frames are removed.
- [ ] Every image link points to a file in `frames/` next to the Markdown.
- [ ] Image alt text says what the frame shows.

## Format

- [ ] The structure matches the chosen format.
- [ ] Code blocks have a language tag.
- [ ] No em dash or en dash characters, no emojis.
- [ ] The draft comment from `assemble_draft.py` is deleted.

## Delivery

- [ ] The `work/` folder is deleted (or the user asked to keep it).
- [ ] The reply is in the user's language and gives the file path, the format, and anything you could not verify.
