AD-INF-01 / deterministic pipeline

How HTML graphics are made

01

Write the composition

Language models reason about hierarchy and write HTML, CSS, and SVG. No picture model is involved.

02

Lock the artboard

Exact pixel dimensions, licensed fonts from Bunny, Lucide marks, user or public-domain images only.

03

Render in a browser

Chromium paints the document. Live Mode selects real elements. Accept writes source, then re-renders.

04

Export pixels

PNG, JPEG, SVG, or PDF from the same HTML. Audit checks overflow, fonts, and assets before shipping.

ArtDirector / HTML in. Pixels out. Never a generative image API.
