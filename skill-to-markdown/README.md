# skill-to-markdown

Convert a `SKILL.md` file into clean, readable Markdown documentation. Extracts frontmatter, instructions, and structure into a formatted doc suitable for sharing, README files, or documentation.

## Core Rule
All skills in this repository must instruct agents to respond in the user's language regardless of content.

## Usage
1. Provide the path to a `SKILL.md` file or the skill name
2. Specify output preferences (TOC, include frontmatter, etc.)
3. The skill will parse and convert it to clean documentation

## Features
- Parses frontmatter and content
- Converts agent instructions to human-readable docs
- Preserves code blocks and examples
- Optional table of contents
- Clean formatting
- Works with any SKILL.md in standard format
